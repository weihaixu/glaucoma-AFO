# 纯干实验版方案与操作流程

> 适用情形：没有细胞房/动物房、没有伦理批件、时间或经费不足以做湿实验，但仍需完成一份站得住的开题与一篇可发表的论文。
> 配套：`docs/操作手册-从环境到成图.md`（上机细节）、`docs/实验SOP-课题三.md`（原湿实验版，留作将来有条件时启用）。

## 0. 先回答"可不可行"

**可行，但必须换一个证据结构。**

湿实验的作用是提供"干预证据"：敲掉基因→表型改变。没有它，你的证据链会缺最高一级。纯干实验能补到"因果推断 + 细胞定位 + 计算扰动"这一层，达不到"干预验证"，但只要把这三层做扎实，眼科主流期刊（IF 3–5）是收的，做得好可以冲 5 分以上。

### 0.1 什么样的纯生信会被拒

| 特征 | 审稿人原话（大意） |
|---|---|
| 单一数据集、无外部验证 | "findings are not validated in an independent cohort" |
| 只做 DEG + GO/KEGG + hub + ROC | "a standard bioinformatics workflow with limited novelty" |
| AUC 0.95 但无校准、无 CI | "likely overfitted" |
| 结论停在"X 可能是标志物" | "no mechanistic insight" |
| 免疫浸润用 LM22 套眼组织 | "cell composition estimates are not credible" |

### 0.2 什么样的纯生信能过

四个条件，缺一不可：

1. **多队列 + 跨平台 + 跨物种**：同一结论在 3 个以上独立数据源里方向一致；
2. **落到细胞类型**：不是"小梁网组织里某基因升高"，而是"JCT 亚群中某配体-受体轴增强"；
3. **因果推断**：MR + 共定位 + 中介分析，把"关联"推到"遗传因果"；
4. **可检验的预测**：明确写出"若在 HTM 细胞中敲低 X，应观察到 Y"，让后来者能验证你。

### 0.3 证据等级与替代关系（这张表决定你怎么写讨论）

| 证据等级 | 湿实验版 | 纯干实验版的替代 | 能写到什么程度 |
|---|---|---|---|
| 关联 | DEG、WGCNA | 同（多队列） | "与疾病相关" |
| 细胞定位 | 免疫荧光 | 单细胞 + 公共 IHC 图像（HPA） | "定位于某细胞类型" |
| 因果 | 敲降/过表达 | MR + coloc + TWAS + 中介 MR | "遗传证据支持因果" |
| 干预 | 抑制剂/动物模型 | 计算扰动 + CMap 逆转 | "预测该靶点可逆转疾病程序" |
| 表型 | 外流阻力测定 | **无法替代** | 只能写"推测影响房水外流" |

**最后一行是关键**：没有外流实验，就不要在摘要里写"改善房水外流"，写"提示可能影响房水外流阻力"，并在 Limitations 明确说明。

## 1. 重新设计的三个课题

保留原假说（机械微环境—YAP—ECM 正反馈），但把三个课题的**验证手段**全部换成计算。

### 课题一：小梁网细胞状态图谱与分子轴（多队列 + 跨物种）

| 项 | 内容 |
|---|---|
| 问题 | 房水外流阻力增加时，哪一类 TM/JCT 细胞状态发生了改变？其分子轴是什么？ |
| 数据 | 人 TM bulk：GSE27276（训练）、GSE4316（验证）；人 ONH：GSE45570（通路层面验证）；人 TM scRNA：GSE313736；猴房角：GSE231749；小鼠 TM：GSE309500 |
| 关键分析 | ① 多队列 DEG 与共识基因；② WGCNA 模块与 IOP/MD 连续变量关联；③ 单细胞亚群（基质型/收缩型/炎症样）与拟时序；④ **跨物种模块保守性**（人-猴-鼠同源基因的模块重叠） |
| 核心产出 | 1–2 个"细胞状态特异的分子轴"，例如"JCT 中 TGFβ2→LOXL1→胶原交联" |
| 为什么这样能替代实验 | 跨物种一致性是"生物学真实性"的强证据；湿实验里用小鼠模型验证人结果，逻辑上等价于这里用小鼠/猴数据验证人数据 |

### 课题二：遗传因果链（把关联推到因果）

| 项 | 内容 |
|---|---|
| 问题 | 候选基因是 POAG 的因果基因吗？作用是否经由眼压？ |
| 数据 | FinnGen R12 POAG；UKB/已发表 IOP GWAS；GTEx v8 eQTL；UKB-PPP pQTL；1000G EUR LD |
| 关键分析 | ① coloc（PP.H4>0.8）；② FUSION TWAS + FOCUS；③ 顺式 eQTL 的 MR（IVW/Egger/WM/PRESSO）；④ **两阶段 MR：表达→IOP→POAG**；⑤ **多变量 MR** 区分"经 IOP"与"独立于 IOP" |
| 核心产出 | 2–4 个有三法一致证据的基因；每个基因标注"经 IOP"或"独立于 IOP" |
| 为什么能替代实验 | 遗传工具变量是天然的"随机分配"，在因果推断的层级上强于体外敲降（后者常被质疑生理相关性） |

### 课题三：计算扰动与药物重定位（干预的替代）

| 项 | 内容 |
|---|---|
| 问题 | 敲低候选基因能否逆转疾病转录程序？有没有可重定位的药物？ |
| 数据 | 课题一的单细胞对象；课题一的共识基因表；LINCS L1000 / CMap（可选） |
| 关键分析 | ① 网络传播式 in silico 敲除（`11`）；② 与疾病特征的方向一致性 + 度数匹配置换检验；③ 药物签名连通性（`13` C 部分）；④ 标签置换零分布 + 多管线稳健性（`13` A/B） |
| 核心产出 | "驱动基因"排序 + 5–10 个候选化合物 + 稳健性区间 |
| 表述红线 | 只能写 "in silico perturbation predicts"、"candidate compounds"，不能写 "inhibits"、"ameliorates" |

## 2. 与湿实验版的差异一览

| 原方案 | 新版 | 影响 |
|---|---|---|
| 课题三：原代 HTM + 牵张 + 水凝胶 + 动物 | 计算扰动 + 药物连通性 + 稳健性 | 结论强度下降一级，但可完成度从 60% 提到 95% |
| 预期 IF 5–8（含实验） | 3–5（纯计算），做得好可上探 5+ | 投稿策略要改：先投眼科主流，被拒转多组学综合刊 |
| 周期 9–12 个月 | **12–16 周** | 可在一个学期内完成 |
| 成本 15–30 万 | < 1 万（服务器/查重/版面费） | 适合自费或小额度课题 |
| 风险：细胞污染、动物脱落 | 风险：数据不可得、结论被质疑"只是相关" | 风险类型变了，止损点也要重设 |

### 4.3 第 2 周：拿数据

按操作手册第 3 节执行，额外做两件事：

1. **IOP GWAS 的列名映射**。不同来源列名差异大（`BETA/SE/P/A1/A2/FRQ` 或 `beta/se/pval/alt/ref/af_alt`），统一在 `config.yml` 的 `drylab.mediation.cols` 里映射。先用 `head` 看前 5 行再填，不要猜。
2. **单细胞数据的物种注释**。人/猴/鼠三套数据的基因名格式不同（`GENE` vs `Gene` vs `gene`），建网前要统一成大写，否则跨物种比较全是空集。

```r
# 统一基因名（在 06 之后、11 之前做一次）
obj <- readRDS("data/processed/scRNA_ref.rds")
m <- Seurat::GetAssayData(obj, assay = "RNA", layer = "counts")
rownames(m) <- toupper(rownames(m))
m <- m[!duplicated(rownames(m)), ]
obj[["RNA"]] <- Seurat::CreateAssayObject(counts = m)
saveRDS(obj, "data/processed/scRNA_ref.rds")
```

g <- Reduce(intersect, lapply(d, `[[`, "gene"))

cat("三队列共同基因:", length(g), "\n")

Rscript 06_scrna_cellchat.R          # 人 TM
# 猴、鼠数据：复制 config 里的 scrna 段，分别指向不同 rds，输出改后缀重跑

**跨物种保守性**（纯干实验版的加分项，湿实验版里靠小鼠模型实现）。已封装成 `14_cross_species.R`，不用手写：

```bash
# 1) 先把三套对象统一基因名（人/猴大多已是大写，鼠需要 toupper）
# 2) config 里登记物种 -> 对象路径
#    drylab:
#      cross_species:
#        objects: {macaque: "data/processed/scRNA_macaque.rds",
#                  mouse:   "data/processed/scRNA_mouse.rds"}
#        celltypes: {macaque: ["TM","JCT"], mouse: ["TM"]}
Rscript 14_cross_species.R
```

脚本做三件事，对应三张图：

| 步骤 | 做什么 | 输出 | 判读 |
|---|---|---|---|
| A 伪批量差异 | 每个 物种×细胞类型 内部 case vs control，只在人共识基因上做 Wilcoxon | `xspecies_de.tsv` | 逐基因看 `direction_match` |
| B 一致性统计 | 方向一致比例 + 二项检验；logFC 的 Spearman ρ | `xspecies_concordance.tsv` | **≥0.70 且 binom_p<0.05** 才算保守 |
| C 模块打分 | 人上调/下调基因集给每个细胞打分（AddModuleScore），比 case vs control 的 AUC | `xspecies_modulescore.tsv` | AUC>0.55 且 P<0.05 支持同向 |

关于同源映射，脚本的默认行为与局限要说清：不给 `ortholog_table` 时用 `toupper()` 近似（`Lox`→`LOX` 可行，但 `Cdk2ap1` 这类命名不一致的会丢）。正式分析建议导一张表：

```r
# 一次性导出，存 data/annotation/ortholog_mouse.tsv（列名：human_symbol / mouse_symbol）
library(biomaRt)
human <- useMart("ensembl", dataset = "hsapiens_gene_ensembl")
mouse <- useMart("ensembl", dataset = "mmusculus_gene_ensembl")
hom <- getLDS(attributes = c("mgi_symbol"), filters = "mgi_symbol",
              values = unique(mouse_genes), mart = mouse,
              attributesL = c("hgnc_symbol"), martL = human)
write.table(hom, "data/annotation/ortholog_mouse.tsv", sep = "\t",
            quote = FALSE, row.names = FALSE)
```

判读：保守基因里应出现胶原/LOX 家族（物种间高度保守）。若 concordance < 0.70，不要写"跨物种验证"，改写为"人源发现未能在其他物种重现"，并讨论是模型阶段差异（猴是 POAG 晚期、鼠是急性高眼压）还是映射问题——这个讨论本身就是审稿人认可的诚实。

### 4.7 第 10–12 周：遗传因果（G4）

```bash
Rscript 07_gwas_qc.R
Rscript 08_coloc_smr.R
Rscript 09_twas_focus.R
Rscript 10_mr.R
```

**新增一个必做的一致性表**（这是纯干实验版的核心表，替代湿实验的"必要性"证据）：

| 基因 | coloc H4 | TWAS P | MR P | FDR | 中介比例 | 结论 |
|---|---|---|---|---|---|---|
| LOX | 0.96 | 1e-5 | 0.003 | 0.02 | 0.61 | 经 IOP 通路，强证据 |
| LOXL1 | 0.31 | 0.04 | 0.21 | 0.4 | — | 仅提示 |
| MYOC | 0.12 | 0.9 | 0.8 | — | — | 阴性（已知孟德尔基因，作为阳性对照说明方法可靠） |

**MYOC 这一行很重要**：它是已知的 POAG 孟德尔基因，如果它在你的流程里"阴性"，要么是数据问题，要么说明 eQTL 组织不对（MYOC 在 TM 表达，GTEx 没有 TM）。把这个矛盾如实写进讨论，比藏起来强。

### 4.8 第 13 周：中介 MR

```bash
Rscript 12_mediation_mr.R
```

前置：`data/raw/iop_gwas.tsv.gz` 已放好，`drylab.mediation.cols` 已映射。

判读：

| 结果 | 解释 | 怎么写 |
|---|---|---|
| 间接 P<0.05，中介比例 0.2–0.8，直接效应 P>0.05 | 效应基本经 IOP | "expression affects POAG predominantly through IOP" |
| 间接 P<0.05，直接效应也 P<0.05 | 部分中介 | "partially mediated by IOP" |
| 中介比例 >1 或 <0 | 两段方向不一致 | 不要硬解释，报"inconsistent direction, not interpretable as mediation" |
| 第二段 IOP→POAG 不显著 | IOP 工具变量太弱 | 换更大样本的 IOP GWAS，或放弃中介分析只报总效应 |

### 4.9 第 14 周：计算扰动

```bash
Rscript 11_insilico_perturbation.R
```

前置：`config$scrna.rds` 指向含 `cell_type` 的单细胞对象；`deg_consensus.tsv` 已生成；`drylab.perturbation.target_genes` 填你从课题二筛出的 2–4 个基因。

判读 `perturb_summary.tsv`：

- `score < 0` 且 `p_perm < 0.05`：敲低该基因会**逆转**疾病程序 → 该基因是驱动性的，可作为干预靶点；
- `score > 0` 且显著：敲低会加重疾病方向 → 该基因是保护性的（也可以是发现，但故事要改）；
- `concordance` 在 0.5 附近：该基因对转录程序几乎没有影响，别硬讲。

**这一步的表述模板**：

> In silico perturbation of LOX in the JCT subpopulation shifted the transcriptome away from the POAG-associated program (score = −0.42, P_perm = 0.003, 1,000 degree-matched permutations), predicting that LOX inhibition would partially reverse the disease signature. This prediction remains to be tested experimentally.

最后一句必须写。

### 4.10 第 15 周：稳健性与药物预测

```bash
Rscript 13_robustness_cmap.R
```

判读：

- `robustness_permutation.tsv`：`p_empirical` 应 <0.05，且观测 AUC 明显高于零分布的 95% 分位；
- `robustness_multiverse.tsv`：8 种管线组合的 AUC 范围。**写文章时报范围和最小值**，例如 "AUC ranged from 0.78 to 0.86 across eight analysis pipelines"，比报一个 0.89 可信得多；
- `cmap_connectivity.tsv`（若配了 LINCS）：`cs` 最负的化合物是"可能逆转疾病特征"的候选，按靶点归类后挑 3–5 个写进讨论。

## 6. 期刊策略

| 档位 | 期刊类型 | 需要什么 | 命中率 |
|---|---|---|---|
| 第一档（IF 5–7） | 眼科主流（如 IOVS 一类） | 三法遗传证据 + 单细胞 + 扰动预测全齐，且假说新 | 低，值得试一次 |
| 第二档（IF 3–5） | 眼科专业刊（Exp Eye Res、J Glaucoma 一类） | 多队列 + 单细胞 + MR 即可 | 中 |
| 第三档（IF 2–4） | 多组学/遗传综合刊、Frontiers 系列 | 流程完整、图表规范即可 | 高 |
| 保底 | 开放获取眼科刊 | — | 高，但版面费高 |

**投稿顺序建议**：第一档投出后 2–4 周被拒（desk rejection 通常很快），立刻转第二档，不要等。Cover letter 里主动写清楚"本研究为计算分析，未做实验验证，但通过多队列、跨物种与遗传因果三层证据补偿"，比被审稿人指出来好。

## 7. 审稿人必问与回答模板

| 质疑 | 回答要点 |
|---|---|
| 没有实验验证 | 承认局限；指出遗传工具变量在因果推断层级上不弱于体外敲降；给出可检验预测清单 |
| 公共数据二次分析，新颖性不足 | 强调三点新意：跨物种保守性、中介 MR 拆解 IOP 通路、计算扰动给出靶点排序 |
| 单细胞来自不同平台，能合并吗 | 说明只做"独立分析后比较"，不做跨平台整合；给出各自 QC 参数 |
| 反卷积结果可信吗 | 用自建 signature 而非 LM22；与单细胞比例交叉验证；报告比例和 |
| MR 样本重叠 | 暴露（GTEx/eQTL）与结局（FinnGen）独立；如用 UKB 暴露需 MRlap 校正 |
| 中介 MR 的假设太强 | 列出四个假设（无未测混杂、无暴露-中介交互、两段独立、线性），逐条说明与偏离方向 |
| in silico 扰动只是相关网络 | 明确它是"网络传播模型，非因果"；用置换检验与度数匹配控制假阳性；只作为预测 |
| AUC 是不是过拟合 | 报 8 条管线的范围、外部验证、校准曲线，不给单点最优值 |
| 为什么不用 TM 特异 eQTL | GTEx 无 TM；改用 GSE313736 或 EyeGEx，并说明代理组织的局限 |
| 结论对临床有什么意义 | 给可检验的预测 + 候选化合物，不承诺疗效 |

## 8. 风险与止损

| 风险 | 触发信号 | 止损动作 |
|---|---|---|
| 单细胞数据太大跑不动 | 内存溢出 | 先 subset 到 TM/JCT，再降采样至 2 万细胞 |
| IOP GWAS 拿不到 | 申请被拒 | 放弃中介 MR，改做"多变量 MR 调整 BMI/年龄"，故事改成"独立于 IOP 的机制" |
| 共定位全阴性 | PP.H4 全 <0.5 | 换组织（动脉/神经），或改报阴性结果 + 讨论"非 eQTL 可解释的机制" |
| 计算扰动无显著基因 | P_perm 全 >0.05 | 换目标基因（用 WGCNA hub），或把扰动降级为补充图 |
| 三队列方向一致性差 | 一致性 <50% | 检查分组标签；只保留两个一致的数据集，第三个改作"阴性对照"讨论 |

## 10. 一句话总结

**没有湿实验，不是把实验删掉，而是把"干预证据"换成"遗传因果 + 计算扰动 + 稳健性"三重替代，并把结论的措辞降到证据允许的高度。** 能做到这一点，方案就是可行的；做不到，就会变成又一篇模板生信。
