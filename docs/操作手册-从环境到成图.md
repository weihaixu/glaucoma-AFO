# 操作手册 —— 从装环境到出图（按天执行版）

配套文档：《青光眼房水外流阻力机制研究开题方案.docx》（下称"方案"）、`glaucoma_R_pipeline/` 脚本目录、`实验SOP-课题三.md`。

这份手册只回答一个问题：**明天早上坐下，第一件事做什么，做完怎么知道做对了。**

## 0. 使用说明

### 0.1 三条线并行，不要串行

| 线 | 内容 | 谁来推 | 卡点 |
|---|---|---|---|
| 上机线 | 课题一（01–06）+ 课题二（07–10） | 你 | 数据下载、包版本、判读 |
| 实验线 | 课题三（细胞 + 动物） | 你 + 实验室 | 原代细胞、伦理批件、设备档期 |
| 写作线 | 图 1 机制示意图、方法学段落 | 你 | 拖延 |

**并行原则**：实验线最先启动，因为伦理批件和原代细胞周期最长（4–8 周），上机线可以边等边跑。

### 0.2 五道门禁（Gate）

每道门禁不通过，不许进下一段。这是给自己设的止损点，也是方案里"继续—终止判据"的落地方式。

| 门禁 | 时点 | 通过条件 | 不通过怎么办 |
|---|---|---|---|
| G1 | 第 1 周末 | demo 全链路跑通，coloc PP.H4>0.9、MR IVW p<0.05 | 环境问题，回 1.7 排查 |
| G2 | 第 4 周末 | 训练集 DEG 显著基因 50–800 个；WGCNA 至少 1 个模块与 IOP 或 MD 相关 p<0.05 | 改阈值/换数据集；连续变量实在没有就降级为仅 DEG+GSVA |
| G3 | 第 8 周末 | 单细胞拿到 TM/JCT 亚群，CellChat 有组间差异通路 | 换数据集（GSE231749 → GSE313736）或先只做 bulk |
| G4 | 第 12 周末 | 至少 2 个基因同时有 coloc PP.H4>0.8 与 TWAS 显著 | 收缩到 1 个基因 + MR 支持，或改走 pQTL 路线 |
| G5 | 第 16 周末 | 细胞实验重复出 CMS+TGFβ2 协同效应（n=3 donors） | 改力学参数（8%/1.5 Hz），加 Schlemm 管内皮共培养 |

### 0.3 留痕规矩（现在不做，投稿时要重跑）

1. 每次跑完，`results/` 复制一份到 `archive/YYYYMMDD_results/`；
2. 每个阶段结束存 `sessionInfo()` 到 `logs/sessionInfo_<阶段>.txt`；
3. 所有手改的参数，记在 `logs/参数变更.md`（日期、参数、原因、影响哪个图）；
4. 图不要用 PPT 拼，用 Illustrator 或 Inkscape 组版，字号统一 7–8 pt，导出 300 dpi（线条图 600 dpi）。

```r
# 存环境快照，每个阶段结束跑一次
writeLines(capture.output(sessionInfo()), "logs/sessionInfo_20261101.txt")
```

### 1.7 安装故障对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| `there is no package called 'xxx'` 装完还在 | 装到了别的 library | `.libPaths()` 看路径；`install.packages(..., lib = .libPaths()[1])` |
| `Bioconductor version too old` | BiocManager 与 R 版本不匹配 | 按 1.4 的版本号表改 `version=` |
| `dependencies 'xxx' are not available` | 镜像同步延迟 | 换 `https://cloud.r-project.org` 重试 |
| `Rtools is not installed` / 编译报错 | Rtools 版本不对或未进 PATH | `Sys.which("make")` 应为空则重装 Rtools 并勾选 PATH |
| `SeuratObject` 版本冲突 | Seurat 5 与旧包 | `install.packages("SeuratObject")` 升到最新 |
| CellChat 报 `slot` 相关错 | Seurat v5 用 layer | 升级 CellChat ≥ 2.0，脚本已有兜底 |
| 中文图里全是方框 | PDF 设备无中文字体 | 图里全用英文；或 `grDevices::cairo_pdf`（`save_fig` 已优先用 cairo） |
| `cannot open file ... Permission denied` | OneDrive/杀软锁定 | 项目放 `D:\work\` 这类非同步目录 |

|---|---|---|---|
| 差异基因 | `results_demo/tables/deg_DEMO.tsv` | 显著基因 10–60 个，LOX/TGFB2/COL1A1 在列 | 0 个 → 标准化或分组反了 |

## 3. 第 6–10 天：拿数据（唯一不能自动化的环节）

### 3.1 GEO 五步核对法（每组数据都要走）

脚本能下载矩阵，但**不能替你确认哪一列是病例**。分组错了，后面全错，而且不会报错。

1. 打开 `https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE27276`；
2. 滚到 **Samples** 表，看每行的 `title` 和 `characteristics`；
3. 抄下 GSM 号 → 分组 → 临床变量，做成 CSV（见 3.2）；
4. 看 **Platforms** 确认 GPL 号，和 config 里写的是否一致（不一致就改 config，别改脚本）；
5. 看 **Series Matrix File(s)** 的补充材料，临床变量常常只在 `*_series_matrix.txt.gz` 的 `!Sample_characteristics` 里，或者在文章附表里。

### 3.2 建 sample sheet 模板

`data/annotation/sample_sheet_<GSE>.csv`，字段固定：

```csv
sample_id,gsm,group,age,sex,IOP,MD,CCT,batch,donor,note
S1,GSM674456,POAG,67,M,26.5,-12.3,512,batch1,D01,
S2,GSM674457,control,58,F,15.2,-1.1,545,batch1,D02,
```

**必须填的**：`sample_id`（与表达矩阵列名一致）、`group`（POAG/control，小写统一）、`batch`（没有就全填 1）。
**能填就填的**：`IOP / MD / CCT / age`——03 的 WGCNA 靠这几个连续变量拉开与"模板文章"的差距。

填完自查：

```r
ss <- read.csv("data/annotation/sample_sheet_GSE27276.csv")
table(ss$group)                    # 应为 17 / 19
sum(duplicated(ss$sample_id))      # 应为 0
colSums(!is.na(ss[, c("IOP","MD","CCT","age")]))   # 每一列的可用样本数
```

### 3.3 三个 bulk 数据集的分工

| GSE | 角色 | 分组 | 注意 |
|---|---|---|---|
| GSE27276 | **训练集** | 17 POAG vs 19 对照，人 TM 组织 | 最经典，平台 GPL6883；分组信息在 `characteristics_ch1` |
| GSE4316 | 外部验证 | 青光眼 vs 正常 TM 细胞 | 平台号以页面为准（config 里写的需核对）；样本量小，只做方向一致性 |
| GSE45570 | 外部验证 | 6 vs 6，视神经乳头 | 组织不是 TM，是筛板/ONH；验证的是"共同通路"不是"同一组织" |

验证集用错组织不是问题，**但必须在方法学里写明**："GSE45570 为视神经乳头组织，仅用于验证通路层面的一致性，不用于验证 TM 特异表达。"

### 3.4 单细胞数据

两条路，按你手上的东西选：

**A. 下载处理好的 RDS（最省事）**

GSE313736（人 TM，74 供体，31.7 万细胞，含地塞米松组）与 GSE231749（猴房角，3 vs 3）在 GEO 的 supplementary 里可能提供 `.rds` 或 `.h5ad`。下 `.rds` 直接 `readRDS()`；下 `.h5ad` 用：

```r
sce <- zellkonverter::readH5AD("GSE313736.h5ad")   # BiocManager::install("zellkonverter")
obj <- Seurat::CreateSeuratObject(counts = SummarizedExperiment::assay(sce, "counts"))
obj$cell_type <- sce$cell_type     # 若原文件已注释
saveRDS(obj, "data/processed/scRNA_ref.rds")
```

**B. 自己从 CellRanger 输出建（GSE 给的是 10x 三件套时）**

```r
counts <- Seurat::Read10X("path/to/filtered_feature_bc_matrix")
obj <- Seurat::CreateSeuratObject(counts, project = "TM", min.cells = 3, min.features = 200)
```

**注意**：GSE 上的 10x 数据常被作者打包成 `GSE313736_RAW.tar`，里面每个样本一个文件夹，解压后目录结构要整理成 `sample1/barcodes.tsv.gz`、`features.tsv.gz`、`matrix.mtx.gz`，否则 `Read10X` 读不了。写个小脚本批量整理，别手工点。

单细胞对象要求：至少一列 `cell_type`（或 `seurat_clusters` 让脚本自己注释），一列能区分病例/对照的元数据（`group`、`condition`、`donor`、`treatment` 任一，脚本用 `scrna.group_regex` 正则匹配）。

### 3.5 遗传数据

| 文件 | 从哪下 | 关键点 |
|---|---|---|
| FinnGen R12 POAG | `https://r12.finngen.fi/`，搜端点 `H7_GLAUCOMA` → Download → Summary stats | 文件名形如 `finngen_R12_H7_GLAUCOMA.gz`；列名为 `#chrom, pos, ref, alt, rsids, af_alt, beta, sebeta, pval, mlogp, N` |
| GTEx v8 eQTL | GTEx Portal → Downloads → eQTL → `GTEx_Analysis_v8_eQTL.tar.gz` | 解压后每组织一个 `<Tissue>.v8.EUR.allpairs.txt.gz` + `.tbi`；**必须同时下 `.tbi`**，否则 tabix 读不了 |
| 1000G EUR LD 面板 | FUSION 官网 `1000G.EUR.QC.*`（bed/bim/fam） | 三件套齐全，`plink --bfile` 能打开 |
| FUSION 权重 | FUSION 官网 `weights/` 按组织下 `*.wgt.RDat` + `weights.pos` | 与 eQTL 组织对应；没有眼组织权重，只能用 GTEx 代理 |
| UKB-PPP pQTL | Synapse（需申请） | 只下你关心的基因所在区域，别下全量 |

**眼组织 eQTL 的现实**：GTEx 没有小梁网。可用的替代顺序是 ① GSE313736 的人 TM 单细胞 eQTL（最贴题，但需自己跑 eQTL 流程）；② EyeGEx（视网膜/RPE/脉络膜/视神经，不含 TM）；③ GTEx 动脉/神经作代理并明说局限。这个取舍要写进 Limitations，评审一定会问。

## 4. 课题一上机：01–06（第 11–45 天）

每个脚本固定五问：**跑什么 → 看什么 → 怎么判 → 存什么 → 错了怎么办**。

### 4.1 `01_geo_prepare.R` —— 把矩阵变成能用的数据

```bash
Rscript 01_geo_prepare.R
```

**先改 config**：

```yaml
bulk:
  train:
    gse: "GSE27276"
    gpl: "GPL6883"
    group_regex: "POAG|glaucoma"     # 命中即病例；对照里若含 "glaucoma suspect" 要改
    batch: null                       # 有批次列才填
  valid:
    - gse: "GSE4316"
      gpl: "GPL570"
      group_regex: "glaucoma|POAG"
```

**看什么**（按这个顺序）：

1. `logs/01_geo_prepare.log` 搜三行：`探针合并：xxx 探针 -> yyy 基因`、`过滤后保留 N 个基因`、`标记离群样本`；
2. `results/figures/pca_GSE27276_raw.pdf` 与 `_clean.pdf`；
3. `results/tables/qc_summary.tsv`。

**怎么判**：

| 现象 | 判断 | 动作 |
|---|---|---|
| 基因数 12000–20000（人芯片） | 正常 | 继续 |
| 基因数 < 8000 | 注释表用错了（比如拿到 miRNA 平台） | 核对 GPL 号，删 `data/annotation/GPL*.gz` 重下 |
| PCA 上病例/对照沿 PC1 分开 | 好 | 继续 |
| PCA 上按批次分开 | 批次未校正 | 在 config 填 `batch`，确认 `combat: true` |
| 单个样本远离所有簇（>3 MAD） | 离群 | **先不删**，去 GEO 查这个 GSM 的标题/备注，确认是组织类型不同还是质量差，再决定 |

**离群样本决策树**（这一步做错会被审稿人抓）：

```
离群样本是否在 GEO 里标注为不同组织/不同处理？
├─ 是 → 直接删除，方法学写明理由
├─ 否，但是技术重复或质控失败（3' 端 bias、降解曲线差）→ 删除，写进 QC 表

```

**存什么**：`qc_summary.tsv` 直接就是论文表 S1（数据集、平台、样本量、批次、离群数），把它存成 `tables/TableS1.xlsx` 并补上"临床变量可用数"一列。

### 4.3 `03_wgcna.R` —— 模块与临床连续变量

```bash

```

**前置**：`pheno` 里必须有 `IOP / MD / CCT / age` 中至少一个。没有就先补（见 3.2），否则这步降级为"只做模块划分"，价值减半。

**看什么**：`wgcna_softthreshold_GSE27276.pdf`（软阈值）、`wgcna_module_trait_GSE27276.pdf`（模块-性状热图）、`wgcna_hub_genes.tsv`。

**怎么判**：

1. **软阈值**：曲线第一次到达 R²≥0.8 且斜率转正的那个 power。脚本自动选（`soft_power: null`），但你要看一眼图确认不是选在平台区；

3. **模块-性状图**：看格子里的 `r (P)`。要的不是"与 group 相关"，而是**与 IOP 或 MD 相关且方向符合假说**（例如含 LOX/COL1A1 的模块与 IOP 正相关、与 MD 负相关）；
4. **hub 基因**：`kME > 0.8` 且 `|GS| > 0.3`。脚本输出的表里两列都有，自己按这个卡。

**这一步的产出怎么写进文章**：不要写"我们鉴定出 12 个模块"，要写"blue 模块（r=0.62, P=3e-5）与 IOP 正相关，富集于 ECM organization，其 hub 基因 LOX/LOXL1 在单细胞中定位于 TM 基质亚群"——一句话把三个层次串起来。

**样本量警告**：`< 15` 例时 WGCNA 不可靠，脚本会提示。此时只做 DEG + GSVA，方法学里说明原因，比硬跑一个假模块诚实。

### 4.4 `04_enrich_deconv.R` —— 通路与细胞组成

**四个必须守住的规矩**：

### 4.5 `05_ml_signature.R` —— 建模与外部队列

```bash

```

**看什么**：`ml_signature.tsv`（最终基因集）、`model_performance.tsv`（AUC + 95%CI）、`roc_train.pdf`、`roc_valid_GSE4316.pdf`、`calibration.pdf`、`dca.pdf`、`nomogram.pdf`。

**三条反数据泄漏的硬规矩**（这是被拒稿的高频原因）：

1. 特征筛选（LASSO/SVM-RFE/RF）**只在训练集内**做，验证集一次都不能碰；
2. 交叉验证的折内做筛选，不能在全数据上筛完再 CV（脚本已按折内做，你换代码时别破坏）；
3. 报告 AUC 必须带 95%CI（bootstrap 1000 次），只报点估计会被要求补。

**三法交集为空怎么办**：说明信号弱，不要硬凑。改用"bootstrap 稳定性选择"——重复 200 次重采样，统计每个基因被选中的频率，取频率 >60% 的基因。这比强行交集更站得住脚。

**外部验证的判读**：验证集 AUC 比训练集低 0.05–0.15 属正常；**低于 0.65 就不要写"具有良好诊断价值"**，改为"在独立队列中呈现一致趋势但判别能力有限"，同时把重点转到机制而非诊断。

**列线图（nomogram）**：只有当你打算做"临床预测"时才需要。本课题是机制研究，列线图属于加分项不是必需项，别为它硬凑临床变量。

### 4.6 `06_scrna_cellchat.R` —— 单细胞定位（G3）

```bash
Rscript 06_scrna_cellchat.R
```

**这是全套里最容易出"看起来对但其实错"的一步**，逐项检查：

| 环节 | 正确做法 | 常见错误 |
|---|---|---|
| QC | nFeature 200–8000、MT% <20、doublet 用 `scDblFinder` 去掉 | 只按 MT% 过滤，双细胞混进 TM 群 |
| 批次 | `Harmony` 按 **donor** 整合，不是按 group | 按 group 整合会把生物学差异一起抹掉 |
| 聚类 | resolution 从 0.4 扫到 1.2，看 TM 是否被拆成多群 | 直接 0.8 一把梭 |
| 注释 | marker DotPlot + 原文附表核对（van Zyl 2020 的 TM/JCT/SC marker 表） | 只靠自动注释，TM 与角膜内皮混淆 |
| 通讯 | CellChat 分别在 case/control 建对象再 `mergeCellChat` 比较 | 合并后建一个对象，组间差异被平均掉 |
| 拟时序 | 根节点设在正常组的 TM 细胞 | 随便点一个，轨迹方向反了 |

**注释参考**：TM 群看 `MYOC / MGP / TIMP3 / SFRP1`；JCT 群看 `ANGPTL7`（区分 JCT 与 TM 的经典 marker）；Schlemm 管内皮看 `PECAM1 / PROX1 / CD34`；睫状上皮污染看 `ATP1A1 / ATP1B1`。**最终以 GSE146188（van Zyl 2020）补充表的 marker 组合为准**，不要只信单一基因。

**CellChat 出什么才算成功**：至少一条配体-受体轴在 case 中显著增强，且这条轴的配体来自 TM、受体在 TM/JCT 上表达——例如 `TGFB2-(TGFBR1+TGFBR2)`、`SPP1-(ITGAV+ITGB1)`、`MIF-(CD74+CXCR4)`。只给出"通讯数量增加"没有意义，必须落到具体轴。

**SCENIC**：脚本只导出表达矩阵与细胞标签（`results/scenic/`），因为 pySCENIC 是 Python 工具。跑法：

### 5.5 `10_mr.R` —— 孟德尔随机化

```bash
Rscript 10_mr.R
```

**工具变量来源**：`genetics.mr.exposure` 指向 `data/raw/eqtl_instruments.tsv.gz`，列需含 `SNP, gene, beta, se, ea, nea, eaf, p`（可选 `tissue, pos`）。从 eQTL 结果里挑顺式（±1 Mb）且 `p < 5e-8` 的 SNP，再 LD 剪枝（`r2 < 0.001`，`10 Mb`）。

**必须报的五件事**：

1. **F 统计量**（`F = beta²/se²`），全部 >10，否则弱工具变量偏倚；
2. **主分析 IVW**，敏感性分析 MR-Egger / 加权中位数 / MR-PRESSO；
3. **异质性** Cochran's Q（p>0.05 才可用固定效应 IVW）；
4. **水平多效性** MR-Egger 截距（p>0.05）；
5. **留一法**（`mr_leaveoneout_<gene>.tsv`，看有没有单个 SNP 驱动结果）。

**方向问题**：本设计是"基因表达 → POAG"，用 Steiger 检验确认方向（`steiger: true`）。反向 MR（POAG → 表达）作为补充，用来排除反向因果。

**样本重叠**：暴露（GTEx/eQTL）与结局（FinnGen）是独立样本，这点要在方法学明确写出来——这是审稿人必问项。

**多重检验**：FDR 只在"IVW × 基因数"这一层校正（脚本已按此实现），不要把不同方法混在一起校正。

### 6.2 方法学段落模板（改数字即可用）

> 公共数据来源于 GEO（GSE27276，17 例 POAG 与 19 例对照的小梁网组织；GSE4316、GSE45570 作为外部验证）。原始 series matrix 经 GPL6883 平台注释表重新映射探针，同一基因多探针取平均表达最高者；经 log2 转换、quantile 标准化与 ComBat 批次校正后，以 limma 进行差异表达分析（BH 校正，FDR<0.05，|log2FC|>1）。以 WGCNA（signed network，软阈值 β=…，最小模块 30）构建共表达网络，将模块特征基因与眼压、视野平均缺损、中央角膜厚度做 bicor 相关。通路分析采用 clusterProfiler（背景限定为表达矩阵内基因）与 GSVA（Hallmark，msigdbr 版本 …）。细胞组成采用单细胞参考构建 signature 后以 NNLS 反卷积估计。
>
> 遗传学部分：POAG 汇总统计来自 FinnGen R12（H7_GLAUCOMA）…；eQTL 来自 GTEx v8（组织：…）…；以 coloc.abf 进行共定位（p1=p2=1e-4，p12=1e-5，并对 p12 做 1e-6~1e-4 敏感性分析），PP.H4>0.8 判定为共享因果变异；TWAS 采用 FUSION（权重：…）；MR 以顺式 eQTL（p<5e-8，r²<0.001）为工具变量，主分析为 IVW，敏感性分析包括 MR-Egger、加权中位数与 MR-PRESSO，并报告 Cochran's Q、Egger 截距与留一法结果。

## 9. 故障速查

| 报错/现象 | 定位 | 处理 |
|---|---|---|
| `找不到项目根目录` | 不在 `glaucoma_R_pipeline/` 下 | `setwd()` 过来，或 `cd` 过去 |
| `缺少输入文件：data/raw/xxx` | 数据没放对 | 按 3.5 放；路径写 config |
| `series matrix 表区定位失败` | 下载不完整 | 删 `data/raw/<GSE>_series_matrix.txt.gz` 重跑 01 |
| `stopifnot(!is.na(sym_col))` | GPL 注释表列名不认识 | 打开注释文件看列名，在 `read_gpl_annotation` 的 `cand` 里加一个 |
| WGCNA `samples < 15` | 样本太少 | 该数据集只做 DEG+GSVA |
| `coloc` 全 NA | SNP 未对齐 | 打印 `nrow(merged)`；GTEx 用 chr_pos 键，别用 rsID |
| MR `harmonise` 后 0 个 SNP | 等位基因不匹配 | 检查 eQTL 的 A1 是否为 ALT；检查 build |
| FUSION 报 `plink not found` | PATH 没配 | 把 plink 目录加进 PATH，重启 R |
| CellChat `net$count` 为空 | 只有一类细胞 | 提高 resolution 或放宽 QC |
| 图里中文变方框 | PDF 字体 | 图内一律英文 |
| `cannot allocate vector of size x Gb` | 内存不足 | 单细胞降维前先 `subset` 到目标细胞类型 |
| 结果每次不一样 | 没设种子 | 脚本有 `set.seed(cfg.project.seed)`，自己加的采样步骤也要设 |

## 10. 需要别人配合的事（本周就去办）

1. **伦理批件**：人眼组织（眼库/手术废弃组织）与动物实验两份，周期 4–8 周，先交；
2. **临床数据**：向眼科要 POAG 患者的 IOP、视野 MD、CCT、用药史，最好能对应到 GSE27276 的样本（多数拿不到，那就用作独立队列的相关性分析）；
3. **设备档期**：Flexcell 牵张仪、流变仪（水凝胶标定）、TonoLab（小鼠眼压）、前房灌注装置；
4. **抗体/试剂**：YAP、p-YAP(S127)、TAZ、LOX、MMP2、TIMP1、p-FAK(Y397)、RhoA——先确认实验室现有库存的克隆号与验证状态，再决定买什么；
5. **单细胞测序报价**：若要补自己的 TM 样本（3 例 POAG + 3 例对照），提前询价与排期（通常 2–3 个月）。
